使用 GitHub Pages 搭建免费个人博客

2026-08-09 GitHub 教程

什么是 GitHub Pages

GitHub Pages 是 GitHub 提供的一项免费静态网站托管服务。你可以用它来托管个人主页、项目文档、博客等任何静态网站。它支持自定义域名，自动提供 HTTPS，而且完全免费。

搭建步骤

第一步：创建仓库

在你的 GitHub 账号下创建一个名为 username.github.io 的仓库（将 username 替换为你的 GitHub 用户名）。仓库必须设置为 Public。

第二步：克隆仓库到本地

git clone https://github.com/username/username.github.io.git
cd username.github.io

第三步：创建首页

在仓库根目录创建一个 index.html 文件作为网站的首页。这是访问者打开你的网站时看到的第一页。

<!DOCTYPE html>
<html>
<head>
  <meta charset="UTF-8">
  <title>My Blog</title>
</head>
<body>
  <h1>Hello, World!</h1>
</body>
</html>

第四步：推送代码

git add .
git commit -m "初始化博客"
git push origin main

第五步：启用 Pages

进入仓库的 Settings → Pages，在 Source 下拉菜单中选择 main 分支，点击保存。几分钟后，你的网站就可以通过 https://username.github.io 访问了。

进阶技巧

  • 自定义域名：在 Settings → Pages 中绑定你自己的域名，并在 DNS 中添加 CNAME 记录
  • 使用 Jekyll：GitHub Pages 原生支持 Jekyll 静态站点生成器，可以写 Markdown 自动生成博客
  • GitHub Actions：使用 Actions 可以自动构建和部署 Hugo、Hexo、VitePress 等框架

提示：GitHub Pages 仓库大小限制为 1GB，每月带宽限制为 100GB，对于个人博客来说完全足够。

总结

GitHub Pages 是搭建个人博客最简单、最经济的方式。不需要购买服务器，不需要配置环境，只需要一个 GitHub 账号和基本的 HTML 知识，几分钟就能让你的博客上线。
