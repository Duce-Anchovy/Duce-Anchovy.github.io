Markdown 写作入门指南

2026-08-08 Markdown 写作

什么是 Markdown

Markdown 是一种轻量级标记语言，由 John Gruber 于 2004 年创建。它允许人们使用易读易写的纯文本格式编写文档，然后转换成结构化的 HTML 文档。对于技术博客作者、开发者来说，Markdown 是必备的写作工具。

基础语法

标题

使用 # 号标记标题，一级到六级对应 # 到 ######：

# 一级标题
## 二级标题
### 三级标题

文本样式

  • 粗体：**粗体文字**
  • 斜体：*斜体文字*
  • 删除线：~~删除线~~
  • 行内代码：`代码`

链接与图片

[链接文字](https://example.com)
![图片描述](image.jpg)

列表

- 无序列表项 1
- 无序列表项 2
  - 嵌套列表项

1. 有序列表项 1
2. 有序列表项 2

代码块

使用三个反引号包裹代码，可以指定语言获得语法高亮：

```python
def hello():
    print("Hello, World!")
```

引用

使用 > 符号创建引用：

> 这是一段引用文字
> 可以有多行

推荐工具

  • VS Code：内置 Markdown 预览，配合插件体验极佳
  • Typora：所见即所得的 Markdown 编辑器
  • Obsidian：强大的笔记工具，支持双向链接
  • Notion：支持 Markdown 快捷输入的协作工具

Markdown 的设计哲学是「易读易写」，语法简洁但功能强大。掌握 Markdown，让你的写作更加高效。

总结

Markdown 是现代技术写作的标配。无论是写博客、写文档、写 README，还是做笔记，Markdown 都能让你专注于内容本身，而不是排版格式。花半小时学习基础语法，受用终生。
